# 콘솔에 올릴 것

앱인토스 콘솔 「앱 정보」 에 그대로 옮겨 적을 값과 이미지다.
규격 근거는 개발자센터 [미니앱 등록하기](https://developers-apps-in-toss.toss.im/guide/operation/console-workspace)
「5-2. 카테고리 및 노출」 이다.

로고는 직접 그린 SVG 를 600×600 으로 찍은 것이다(숫자 10 과 초시계 호, 앱의 세이지·앰버 색).
**토스가 제공하는 아이콘·이미지는 로고로 쓸 수 없다**(2차 가공 포함). 그래서 토스 리소스는 한 장도 섞지 않았다.

### 로고 후보

로고는 콘솔 「앱 정보 › 수정하기 › 2단계」에서 언제든 바꿀 수 있다. 후보 여덟 장을 `logo-candidates/` 에 두었다.
그중 일곱 장은 `logo-candidates/source.html` 에서 나왔다. 크롬으로 열어 600×600 요소를 찍으면 같은 그림이 나온다.
`piggy-flat.png` 만 그 전부터 쓰던 옛 로고라 `source.html` 에 없다.

스크린샷은 그린 그림이 아니라 **실제로 도는 화면을 찍은 것**이다. Playwright 가 운영 빌드를
실제 백엔드에 붙여 조작하면서 찍는다(`scripts/` 에 없고 회차마다 만든다. 다시 찍으려면
`docs/DEPLOY.md` 「실기기 테스트」 순서로 서버를 띄운 뒤 찍는다).

## 앱 정보 문안

### 앱 이름 (국문)
```
10초 가계부
```

### 앱 이름 (영문)
15자 이내 · 명사형 · 명령문 금지.
```
Pocket Ledger
```

### appName
**한 번 등록하면 못 바꾼다.** `frontend/apps-in-toss.config.ts` 의 값과 반드시 같아야 한다.
`pocket` 은 콘솔에서 이미 다른 앱이 쓰고 있어 받지 못했다(2026-09-08).
```
pocket-ledger
```

### 부제
**콘솔 상한 20자.** 특수문자는 `:` `·` `?` 셋만 쓸 수 있다(쉼표도 안 된다. 2026-09-09 폼 검증에서 확인).
비속어 금지. 예전 문안 22자는 넘쳤다.
```
쓰고 10초 · 그걸로 끝나는 가계부
```

### 상세 설명
**콘솔 상한 500자.** 「접속 → 행동 → 결과」 흐름으로 적는다. 콘솔이 이 글을 보고 토스 홈 광고 대상을 고른다.
(2026-09-08 폼에서 확인. 아래는 418자. 두괄식 마케팅 톤으로 고쳐 콘솔에 넣은 문안)
```
가계부, 이번엔 10초면 끝나요. 열자마자 '10초 기록' 버튼 하나. 금액 누르고 분류 고르면 저장 끝, 남은 예산과 오늘 쓸 수 있는 돈이 바로 떠요. 예산도 분류도 미리 묻지 않고, 잘못 눌러도 8초 안에 되돌려요.

귀찮으면 안 적어도 돼요. 결제 알림 캡처 한 장 던지면 여러 건이 한 번에 들어오고, 영수증은 찍기만 하면 총액과 상호를 읽어요. 한 줄에 몇 건을 적어도 알아서 끊어 읽고, 저장 전에 목록으로 보여줘서 고치기도 쉬워요.

며칠 빼먹어도 잔소리 없어요. '밀린 내역 한 번에 정리' 버튼으로 캡처 한 장이면 다시 이어져요.

예산은 숫자 하나면 충분해요. 남은 돈과 하루 가용액이 홈에 뜨고, 리포트에서 어디에 얼마 썼는지 지난달과 견줘 봐요.

세 번 넘게 가계부를 포기한 사람을 위해 만들었어요. 이번엔 진짜 이어져요.
```

### 카테고리
콘솔 트리는 **생활 › 재테크 › 재테크** (비게임의 1단계는 「생활」 하나뿐이다, 2026-09-08 확인). 실제 서비스와 다르면 검토에서 바꿔 준다.

### 고객문의 이메일
사용자에게 공개되는 값이라 개인 메일 주소를 그대로 쓸지 정하고 넣는다.

### 사용 연령
만 19세 이상. 앱인토스가 지금 그 이상에게만 제공한다. 우리가 고를 것은 없다.

## 개인정보처리방침

앱 안 `설정 → 개인정보처리방침` 화면(`frontend/src/pages/PrivacyPage.tsx`)이 정본이다.
콘솔이 **외부 URL** 을 요구하면 그 화면 내용을 그대로 옮긴 공개 페이지가 따로 필요하다.
그때 두 곳이 어긋나지 않게 화면을 먼저 고치고 옮긴다.
