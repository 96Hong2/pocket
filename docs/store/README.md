# 콘솔에 올릴 것

앱인토스 콘솔 「앱 정보」 에 그대로 옮겨 적을 값과 이미지다.
규격 근거는 개발자센터 [미니앱 등록하기](https://developers-apps-in-toss.toss.im/guide/operation/console-workspace)
「5-2. 카테고리 및 노출」 이다.

## 파일

| 파일 | 쓰는 자리 | 규격 | 지킨 것 |
| --- | --- | --- | --- |
| `logo-600.png` | 앱 로고 | 600×600 PNG | 정사각형 · 모서리 안 둥글게 · 배경색 있음(세이지700) · 투명 아님 |
| `store-1-home.png` | 스크린샷 1 | 636×1048 PNG | 세로형 최소 3장 요건을 넘는 4장 |
| `store-2-record.png` | 스크린샷 2 | 636×1048 PNG | |
| `store-3-feedback.png` | 스크린샷 3 | 636×1048 PNG | |
| `store-4-report.png` | 스크린샷 4 | 636×1048 PNG | |

로고의 돼지저금통은 이 저장소가 쓰는 아이콘 세트에서 왔다. **토스가 제공하는 아이콘·이미지는
로고로 쓸 수 없다**(2차 가공 포함). 그래서 토스 리소스는 한 장도 섞지 않았다.

스크린샷은 그린 그림이 아니라 **실제로 도는 화면을 찍은 것**이다. Playwright 가 운영 빌드를
실제 백엔드에 붙여 조작하면서 찍는다(`scripts/` 에 없고 회차마다 만든다. 다시 찍으려면
`docs/DEPLOY.md` 「실기기 테스트」 순서로 서버를 띄운 뒤 찍는다).

## 앱 정보 문안

### 앱 이름 (국문)
```
10초 가계부
```

### 앱 이름 (영문)
15자 이내 · 명사형 · 명령문 금지.
```
Pocket Ledger
```

### appName
**한 번 등록하면 못 바꾼다.** `frontend/apps-in-toss.config.ts` 의 값과 반드시 같아야 한다.
`pocket` 은 콘솔에서 이미 다른 앱이 쓰고 있어 받지 못했다(2026-09-08).
```
pocket-ledger
```

### 부제
느낌표와 비속어를 쓸 수 없다.
```
쓰고 나서 10초, 그걸로 끝나는 가계부
```

### 상세 설명
「접속 → 행동 → 결과」 흐름으로 적는다. 콘솔이 이 글을 보고 토스 홈 광고 대상을 고른다.
```
가계부를 세 번 넘게 포기한 사람을 위해 만들었어요. 처음 들어오면 예산도 분류도 묻지 않고
바로 홈이 뜨고, 가운데 '10초 기록' 버튼 하나만 보여요.

버튼을 누르면 키패드가 올라와요. 금액을 누르고 분류를 고르면 그 자리에서 저장돼요.
저장하면 '저장했어요' 로 끝내지 않고 남은 예산과 오늘부터 하루에 얼마씩 쓸 수 있는지를
바로 알려줘요. 잘못 눌렀으면 8초 동안 되돌리기를 누르면 돼요.

키패드 말고도 세 가지 길이 있어요. 한 줄에 여러 건을 적으면 끊어 읽고, 결제 알림 캡처를
한 장 던지면 여러 건을 뽑아 주고, 영수증을 찍으면 총액과 상호를 읽어요. 어느 쪽이든
저장 전에 목록으로 보여주고 그 자리에서 고칠 수 있어요. 한 번 고치면 다음부터 기억해요.

관리 탭에서 이번 달 예산을 숫자 하나로 정하면 홈에 남은 돈과 하루 가용액이 생겨요.
카테고리별로 따로 정할 수도 있고, 새 달이 되면 지난달 예산을 그대로 가져와요.

리포트 탭에서는 이번 달에 어디로 얼마가 나갔는지 도넛과 목록으로 보고, 지난달 같은 기간과
견줘 봐요. 최근 여섯 달 흐름도 함께 보여요.

며칠 못 들어와도 지적하지 않아요. 며칠 놓쳤는지 세지 않고, 대신 홈에 '밀린 내역 한 번에
정리' 버튼을 띄워 캡처 한 장으로 돌아올 수 있게 해요.
```

### 카테고리
비게임 · 대분류에서 금융/생활 계열을 고른다. 실제 서비스와 다르면 검토에서 바꿔 준다.

### 고객문의 이메일
사용자에게 공개되는 값이라 개인 메일 주소를 그대로 쓸지 정하고 넣는다.

### 사용 연령
만 19세 이상. 앱인토스가 지금 그 이상에게만 제공한다. 우리가 고를 것은 없다.

## 개인정보처리방침

앱 안 `설정 → 개인정보처리방침` 화면(`frontend/src/pages/PrivacyPage.tsx`)이 정본이다.
콘솔이 **외부 URL** 을 요구하면 그 화면 내용을 그대로 옮긴 공개 페이지가 따로 필요하다.
그때 두 곳이 어긋나지 않게 화면을 먼저 고치고 옮긴다.
